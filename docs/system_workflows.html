5. End-to-end POST /ask sequence

sequenceDiagram
  actor User
  participant API as FastAPI /ask
  participant S as AskService
  participant P as question_parser
  participant R as LawRepository
  participant E as EmbeddingService
  participant L as OpenAI LLM
  participant C as citations

  User->>API: POST question
  API->>S: ask(question)
  S->>P: parse_question()
  alt only out-of-range sections
    S-->>API: supported=false
  else named in-range section
    S->>R: fetch_sections
    R-->>S: direct_section hits
  else open question
    S->>E: embed_query
    S->>R: keyword_search
    S->>R: vector_search
    S->>S: RRF top K
  end
  alt weak or empty evidence
    S-->>API: supported=false
  else
    S->>L: grounded prompt
    L-->>S: JSON answer + citations
    S->>C: validate_citations
    alt invalid citations
      S-->>API: supported=false
    else
      S-->>API: supported=true
    end
  end
  API-->>User: AskResponse

6. Refusal / evidence gates

Weak evidence never reaches the LLM. Invalid citations still force unsupported.

flowchart TD
  Q[Question] --> PARSE[parse_question]
  PARSE --> OOR{Only out-of-range sections?}
  OOR -->|yes| U1[unsupported OUT_OF_RANGE]
  OOR -->|no| RET[_retrieve]
  RET --> HITS{Any hits?}
  HITS -->|no| U2[unsupported NO_EVIDENCE]
  HITS -->|yes| GATE{Evidence strong enough?}
  GATE -->|no| U2
  GATE -->|yes| GEN[LLM generate]
  GEN --> SUP{model supported?}
  SUP -->|no| U3[unsupported MODEL_REFUSED]
  SUP -->|yes| VAL[validate_citations]
  VAL --> OK{valid citation?}
  OK -->|no| U2
  OK -->|yes| OKR[supported=true]

8. Citation validation

flowchart TD
  RAW[LLM citations] --> MAP{evidence_id retrieved?}
  MAP -->|no| DROP[Drop]
  MAP -->|yes| QUOTE[repair_quote]
  QUOTE --> EXACT{Exact substring?}
  EXACT -->|yes| KEEP[verbatim quote]
  EXACT -->|no| LCS{Common run ≥ 30?}
  LCS -->|yes| FIX[repaired quote]
  LCS -->|no| FALL[leading sentences]
  KEEP --> OUT[ValidatedCitation]
  FIX --> OUT
  FALL --> OUT
